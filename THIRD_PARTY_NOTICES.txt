第三方组件与许可声明
====================

本便携包内的「番茄闹钟.exe」是一个 .NET Framework 4 的 WinForms 宿主，
它只做两件事：开一个窗口、用 Microsoft Edge WebView2 显示同目录的
index.html。程序本体不含第三方 JavaScript 库，页面也不发起任何网络请求。

随包分发的三个 DLL 全部来自 Microsoft Edge WebView2，版权归 Microsoft：

  文件名                                  版本来源
  --------------------------------------  ------------------------------
  Microsoft.Web.WebView2.Core.dll         WebView2 SDK（.NET）
  Microsoft.Web.WebView2.WinForms.dll     WebView2 SDK（WinForms 封装）
  WebView2Loader.dll                      WebView2 SDK 的原生加载器（x64）

许可与条款
----------
· Microsoft Edge WebView2 SDK 与 Evergreen 运行时按 Microsoft 的许可条款分发，
  许可证正文见 SDK 包内 LICENSE.txt，或在线文档：
  https://learn.microsoft.com/microsoft-edge/webview2/
· Microsoft、Microsoft Edge、WebView2 是 Microsoft Corporation 的商标。
· 本项目的作者与 Microsoft 无隶属关系，也未获得其背书。

运行时依赖
----------
页面需要目标机器上已安装 "Microsoft Edge WebView2 Runtime (Evergreen)"。
Windows 10/11 通常随 Edge 自带；缺失时双击本目录的
「缺少WebView2时点此安装.url」前往 Microsoft 官方下载页。

字体与图标
----------
页面里的图标是内联 SVG（作者自绘），字体使用系统自带的
Microsoft YaHei UI / Segoe UI，不随包分发任何字体文件。
